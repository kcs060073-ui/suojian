## 隔离解压冒烟

将最终候选 ZIP 解压到新建系统临时目录，使用已验证的本机 Python 运行时从解压目录启动 `workbench.server`，数据库写入解压目录下新建的 `runtime/workbench/smoke.sqlite`，独立端口 `127.0.0.1:18765` 返回 HTTP 200。测试结束后只终止该进程并删除已校验位于系统临时目录内的冒烟目录。

## 尚未完成的现场门禁

以下项目必须在一台未安装项目开发环境的普通同事 Windows 电脑上继续验证：

1. 双击 `安装CUTROOM.bat` 后，winget 能在公司网络和安全策略下安装缺失依赖；
2. 首次安装总耗时、下载失败提示和重试体验可接受；
3. 双击 `启动CUTROOM.bat` 能正常打开工作台；
4. 以普通用户身份配置模型、登记素材目录并完成一条非付费测试任务；
5. 移动硬盘、长中文路径、磁盘空间不足与杀毒软件环境符合预期。

因此本记录支持“私有 Beta 可发布”，不支持“所有普通同事电脑已验证”或“正式稳定版已完成”的表述。
