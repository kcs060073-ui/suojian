# 信息流广告字幕显示规则

原始文案、分镜文本和配音输入保持完整。字幕排版单独生成 `displayText`，不改变镜头或配音时间。

- 使用中文词边界，优先在自然停顿或完整短语之间换行，不再按第 N 个字符硬切。
- 相邻镜头如果把一句话切开，会在行数限制内把字幕延续到镜头切换处；一个字幕跨镜头只显示一次，字幕时间覆盖整段短语。
- 数字、小数、数值范围和单位连在一起；保护常见招商短语和冒号前的短专名。可在字幕预设的 `protected_terms` 中补充固定名称。
- 根据预设 `max_chars_per_line`、`max_lines` 排版；避免单独的标点行和只有一两个字的尾行。英文和数字按较窄的实际字形估算。
- 隐藏每行首尾的分句标点，保留行内标点、小数点、百分号和单位。原文中的标点仍然用于配音。
- 若一个专名或单词超过行宽，保持词组完整，允许该行超出目标字数，不截字、不丢字。
- 不采用按字符比例猜配音时间的方式拆出额外字幕；需要更细时间切分时，应使用真实词级时间戳。

统一规则入口：`src/ad-subtitle-layout.js`。Python 渲染计划、ASS 渲染和质检证据共用该入口。`subtitleLayoutVersion` 随执行方案记录；规则文件纳入候选依赖签名，更新规则后旧候选仍保留，新渲染使用新规则。

例：`上周周边制造业企业选择老厂房续租，` → `上周周边制造业企业` / `选择老厂房续租`；相邻的 `还是换层高11米、` 和 `能上10吨行车的新载体？` 合为一条连续字幕，显示时间为 4.318–8.790 秒。

这是一套可复现的排版规则，不能保证理解任意文案的全部语义。已经锁定的配音分段不会因此重配；跨字幕的口语承接仍须结合实际审片判断。
