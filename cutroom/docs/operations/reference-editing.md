# 参考片编排规则

字幕和视觉镜头分别编排。参考模式使用单行常规字幕，根据 OCR 的常规文字位置及参考帧像素校准位置和主色；长句缩小至安全宽度，保留原 TTS 句级时间，不猜词级时间。

数字强调使用已授权的 `ft-pop` 模板入场思路，将其颜色、描边和字体适配到同一字幕主色。预览以行内数字弹入表现，草稿保留颜色与字体近似，原始剪映模板 ID 不能从压平参考视频恢复。

源片镜头数决定视觉镜头数，镜头时长比例适配真实配音总长。直接切镜跟随参考片；不因每条字幕而新增镜头。

`media_catalog.camera_motion.detect_camera_motion` 在本机对真实帧做光流、RANSAC 全局仿射分析，支持横移、纵移、推近、拉远、静止及无法判断。置信度是粗略测量，不等于准确识别物理拍摄方式。

选材只使用任务范围内已授权素材。优先不同素材、同类场景、相同画幅、时长足够和相同运镜；无精确候选时降级到同类运动、静止或可用画面，记录 `substitution`、实测运动、置信度、短素材循环和重复素材。场景匹配依据文件名，不伪称已理解画面业务内容。

参考策略按任务与确认包装版本写入独立、不可覆盖的 JSON。原片只读、旧候选保留，生成计划及依赖快照记录实际六镜头等编排结果与每一处替代。未绑定参考策略的任务继续使用常规管线。
