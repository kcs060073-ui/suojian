# 园区本地素材库极简检查表设计

日期：2026-08-10  
状态：Peter 已批准设计方向，待书面复核后实施

## 1. 目标

为普通业务人员提供一张可在本地维护的园区素材检查表，同时完成两段验收：

1. 检查要求中的点位和场景是否已经拍全。
2. 检查拍摄内容是否已经整理为可直接用于视频剪辑的本地素材。

该表是岗位必须完成、可定期检查的量化工具。核心验收对象是点位和场景覆盖，不把专业摄影参数变成业务人员的填写负担。

## 2. 使用边界

- 面向所有园区使用，不限定某一种园区类型。
- 每位业务人员在自己的电脑上独立建立和维护素材库。
- 通用资产如配音、BGM、字体、特效和风格模板不进入本表；系统可预置，业务人员也可在本地增加。
- 本表只管理园区业务素材及可组织拍摄的业务场景。
- 食堂、宿舍、保安、保洁、前台等通常难以稳定获得拍摄许可，不纳入统一核心验收。

## 3. 工作簿结构

工作簿只设置一张主表：`园区素材检查表`。

主表顶部显示四个只读汇总指标：

- 基础必备项总数。
- 基础必备项拍摄完成率。
- 基础必备项入库完成率。
- 当前缺口数。

汇总区下方是可筛选的检查明细表。冻结表头，使用下拉选项和条件颜色，不增加独立统计表或复杂操作页。

## 4. 极简字段

| 字段 | 填写规则 |
| --- | --- |
| 一级分类 | 固定分类，不由业务人员自由发挥 |
| 点位/场景 | 一行只写一个可检查对象 |
| 要求等级 | 基础必备 / 有则必备 / 特色可选 |
| 最低要求 | 用一句话说明拍什么以及最低数量 |
| 拍摄状态 | 未拍 / 部分完成 / 已拍全 / 不适用 |
| 入库状态 | 未整理 / 整理中 / 已整理可用 / 不适用 |
| 素材位置 | 填本地文件夹路径或相对目录 |
| 缺口/备注 | 记录缺什么；条件项选“不适用”时说明原因 |

不单独设置景别、运镜、横竖版、原始时长、可用时长、标签和质量等级字段。确有必要的最低拍摄动作合并写入“最低要求”。

## 5. 分类体系

### 5.1 核心分类

1. 园区形象。
2. 公共环境。
3. 产业空间。
4. 基础设施。
5. 交通区位。

### 5.2 补充分类

6. 可组织场景。

生活配套和普通运营服务不作为独立核心分类。确实能够拍摄且有宣传价值的内容，可作为“有则必备”或“特色可选”归入相关分类。

## 6. 要求等级

- 基础必备：几乎所有园区都应具备，必须拍摄并整理入库。
- 有则必备：园区存在该点位、设施或已获得拍摄授权时，必须拍摄并整理；不存在时可标记“不适用”并说明。
- 特色可选：用于体现园区差异化，不影响基础验收结果。

基础必备项不得使用“不适用”规避验收。确有客观原因时，在备注中记录并由检查人确认。

企业考察场景允许业务人员和同事自行组织拍摄，不要求真实客户出镜；不得伪造签约、落户或已成交事实。

## 8. 状态与汇总规则

- 拍摄完成：拍摄状态为“已拍全”。
- 入库完成：入库状态为“已整理可用”。
- 缺口：基础必备项的拍摄状态不是“已拍全”，或入库状态不是“已整理可用”。
- 有则必备项标记“不适用”时，备注必须说明该园区不存在该设施或未获得授权。
- 顶部完成率只计算基础必备项，避免条件项拉低不同园区的可比性。
- 条件格式：未完成为红色，进行中为黄色，完成为绿色，不适用为灰色。

## 9. 本地素材位置规则

表格只记录素材所在文件夹，不要求业务人员逐文件登记。推荐目录结构：

```text
园区名称/
├─ 01_园区形象/
├─ 02_公共环境/
├─ 03_产业空间/
├─ 04_基础设施/
├─ 05_交通区位/
└─ 06_可组织场景/
```

二级文件夹按表中“点位/场景”命名。原始文件和已整理可用片段应在二级文件夹内进一步区分，具体自动化目录规范不在本次极简检查表范围内。

## 10. 验收标准

Excel 实施完成后必须满足：

1. 只有一张业务主表，普通业务人员不需要跨表维护。
2. 8 个填写字段与本设计一致。
3. 所有原表点位均被归类、合并或明确降为条件项，没有无解释丢失。
4. 新增的招商载体、真实运营、到达路线和企业考察场景全部纳入。
5. 下拉选项、条件颜色和顶部汇总正常工作。
6. 基础必备项不能通过“不适用”逃避统计。
7. 表格可筛选、可打印、无文字截断，业务人员无需专业剪辑知识即可理解。

## 11. 暂不纳入

- 素材自动扫描、自动识别和自动打标签。
- 素材缩略图和视频预览界面。
- 多人共享、云端同步和集中素材库。
- 专业摄影参数和逐文件元数据。
- 配音、BGM、字体、特效和风格模板管理。

这些内容属于后续“本地素材资产管理系统”设计，不应阻塞极简检查表先落地。
