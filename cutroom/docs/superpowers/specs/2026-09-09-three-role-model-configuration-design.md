# 剪辑工作台三类模型配置与端到端可用性设计

日期：2026-09-09

## 目标

把用户需要理解和选择的模型能力收敛为三类：

1. **文案策划**：同一个文本模型负责文案分析与改写、分镜规划、包装推荐。
2. **B-roll 画面**：负责缺失画面的远程视频生成；本地素材搜索与匹配仍是内置能力，不要求配置模型。
3. **配音**：负责 TTS 配音与音色试听。

配置流程必须一次走通“供应商连接、模型选择、真实检测、任务可选、任务实际调用”，不允许页面显示保存成功但后续任务仍不可用。

## 方案选择

采用一等能力组，而不是只在界面上合并旧能力。

- 新配置使用 `planning`、`broll`、`tts` 三类能力。
- 新任务只保存这三类选择，其中数字人口播必须有文案策划，信息流广告必须有文案策划和配音；B-roll 远程生成按需启用。
- 文案改写、分镜和包装的执行代码都解析同一个 `planning` 冻结快照。
- 旧任务和旧的 `copywriting`、`storyboard`、`packaging`、`video_generation`、`general_text` 绑定继续可读、可运行；不强制迁移历史任务。

不采用以下方案：

- 仅前端合并、后端仍创建三份文本配置：会产生重复状态和不一致检测。
- 新增“配置包”再包含五个能力：灵活但增加一层用户和代码都不需要的抽象。

## 设置页交互

参考 Open WebUI 的“连接后自动出现模型”和 shadcn/ui 的 Card、Badge、Combobox、Alert 组合，但继续使用项目现有原生 HTML、CSS 和 JavaScript，不引入 React 或新运行时。

页面分成两个清晰区域：

### 连接账号

供应商账号以紧凑卡片展示名称、协议类型、请求地址、默认模型和引用状态。新增连接使用三步向导：

1. 选择用途和供应商类型。
2. 填名称、API Key、请求地址；豆包 TTS 等特殊类型所需字段直接显示。
3. 获取模型并选择一个模型，立即执行真实检测；成功后一次性保存账号与可用配置。

普通 OpenAI 兼容供应商不显示“高级选项”。New API 固定渠道等兼容字段只有选择相应供应商类型时直接出现。

### 三类模型

三张用途卡分别展示文案策划、B-roll 画面、配音。每张卡包含当前默认配置、供应商、模型、检测状态、最近检测时间，以及编辑、重测、删除操作。

状态分为“未检测、检测中、可用、不可用”，失败时在卡片内显示可执行的原因和修复建议。新建任务只展示 24 小时内检测成功的配置。

## URL 与协议归一化

OpenAI 兼容地址同时接受 API 根地址和完整请求地址：

- 根地址示例：`https://open.bigmodel.cn/api/paas/v4`
- 完整文本地址示例：`https://open.bigmodel.cn/api/paas/v4/chat/completions`

系统先规范为 API 根地址，再按能力拼接 `chat/completions`、`models` 或 `audio/speech`。不得硬编码仅识别 `/v1` 或 `/v3`；版本段 `/v4` 等同样有效，也不得重复拼出 `/v4/v1/...`。

模型目录请求成功不等于模型可用。文案策划需要极小真实对话，配音需要极短真实音频，B-roll 只做非付费目录/能力检测，避免自动产生视频费用。

## 数据与兼容

- `model_profiles.capability` 新增使用 `planning` 和 `broll`，表结构无需破坏性迁移。
- 任务绑定仍保存不可变快照和摘要；一个 `planning` 快照被三个文本步骤复用。
- 运行时先读取新能力，找不到时再按旧能力读取历史绑定；绝不在调用失败时静默切换模型。
- API Key 继续只保存到 Windows 凭据管理器，不进入 SQLite、页面响应、日志或任务快照。
- 删除供应商前必须没有任何新旧模型配置引用；删除模型配置前必须没有任务绑定引用。

## 端到端失败处理

- 保存前校验必填字段和 URL 结构。
- 获取模型失败时保留表单，显示鉴权、地址、网络或协议错误，不创建半成品配置。
- 真实检测失败时可以保存连接账号以便修正，但模型配置保持不可用且不能进入任务选择器。
- 任务创建再次校验检测状态、检测时效和快照摘要。
- 实际调用使用任务冻结的供应商、模型和协议；错误返回具体阶段、配置名称和安全错误码。

## 验收门禁

1. 用户为智谱填写名称、Key 和根地址后，可以获取模型、选择 `glm-5.3` 或 `glm-5.3-flash`，真实检测通过。
2. 同一个文案策划配置可完成文案、分镜和包装三种真实调用，不需要配置三次。
3. 新建数字人和信息流广告任务只出现文案策划、B-roll、配音三类选择，并只列可用配置。
4. B-roll 未配置时仍可使用本地素材匹配；启用远程生成时必须选择可用 B-roll 配置并经过费用确认。
5. 配音配置完成后可生成短试听，并能在信息流广告任务中实际生成音频。
6. 页面无“高级选项”，无 `[object HTMLElement]`，状态、错误和下一步操作就地可见。
7. 新旧任务回归、API、真实探测适配器、运行时快照、任务创建和前端交互测试全部通过。

## 非目标

- 不把本地素材匹配误做成必须配置的远程模型。
- 不安装完整 UI 框架或照搬第三方组件代码。
- 不自动发起可能计费的视频生成请求。
- 不删除或重写现有供应商账号、API Key 和历史任务绑定。
