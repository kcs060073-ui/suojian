# 剪辑工作台直连供应商配置设计

日期：2026-09-09

## 目标

剪辑工作台的模型配置采用类似 CC Switch 的两层结构：

1. “供应商”保存连接信息：名称、备注、API Key、API 请求地址和可选默认模型。
2. “能力配置”在文案、分镜、包装、配音、视频生成等能力下选择供应商和具体模型。

普通用户不需要先部署 New API，也不需要理解渠道 ID。一个供应商账号可以被多个能力配置复用，同一能力可以保存多个模型配置，并在新建任务时选择。

## 供应商界面

新增供应商时默认只展示：

- 供应商名称
- 供应商预设
- 备注（可选）
- API Key
- API 请求地址
- 默认模型（可选）

供应商预设至少包括：

- OpenAI 兼容
- 火山方舟文本
- 火山方舟视频生成
- 豆包 TTS
- New API（高级兼容）

预设负责提供默认请求地址、协议和字段提示，但用户可以修改请求地址。支持模型目录的供应商可以点击“获取模型”；不支持时允许手工填写精确模型 ID。

“高级选项”默认折叠，仅放协议覆盖、New API 固定渠道 ID 等少数非日常参数。选择 New API 预设时渠道 ID 仍为可选项，不再是创建供应商的必填字段。

## 能力配置

能力卡片不直接重复保存 API Key，只保存：

- 配置名称
- 供应商账号
- 模型 ID
- 能力专属参数，例如 TTS 音色
- 是否为该能力默认项

文案分析与改写、分镜规划、包装推荐、配音、视频生成、本地素材匹配继续保持独立。任务创建时选择能力配置，创建后冻结供应商、请求地址、模型、协议、音色和高级参数的快照。

## 凭据与执行

API Key 只写入 Windows 凭据管理器，不写入 SQLite、日志、页面响应或任务快照。

执行规则：

- 官方直连或普通 OpenAI 兼容供应商：API Key 原样发送，不追加渠道后缀。
- New API 且配置固定渠道 ID：调用时使用固定渠道路由。
- New API 未配置渠道 ID：按该网关自身的令牌和模型路由规则调用。
- 任务始终使用创建时冻结的配置；凭据缺失、快照被修改或调用失败时直接报错，不静默换供应商或模型。

现有 New API 账号和旧任务继续兼容，不要求重新配置。

## 可用性检测

保存供应商不等于可用。能力配置必须完成对应的真实检测：

- 文本模型：极小对话请求。
- TTS：极短试听音频。
- 视频生成：只做非付费模型/目录检测，不自动创建视频。

只有 24 小时内检测成功的能力配置可以被新任务选择。连接错误应区分请求地址错误、鉴权失败、模型不存在、协议不兼容和网络不可达。

## 验收

- 默认界面不要求 New API、不显示固定渠道 ID。
- 只凭官方 API Key、请求地址和模型 ID 可以完成文本模型配置、检测和任务调用。
- 同一供应商可供多个能力复用；同一能力可配置多个模型。
- 直连密钥不会被追加 New API 渠道后缀。
- New API 高级模式及既有任务保持兼容。
- 页面、API、凭据存储、可用性检测和任务实际调用均有自动化回归测试。

## 非目标

- 不把剪辑工作台做成通用 API 网关。
- 不代替供应商完成账号注册、充值或模型开通。
- 不在页面、SQLite 或项目文件中保存明文密钥。
