# P3 智能深化实施计划

> 依赖：P0/P1/P2 已全部真实验收（项目 + 数字人各 1 条端到端样片、qa 0 阻断、四道人工门禁可追溯）。
> 目标：让「推荐、脚本和规则」能从真实反馈持续改进（路线图 P3 门禁）。

## 范围（取自总控设计 §P3 + 路线图）

| 模块 | 交付物 | 验收 |
| --- | --- | --- |
| M1 规则版本化 | `rule_versions` 表 + 任务锁定创建时版本；`packaging_plan`/`qa` 读锁定版本阈值；CLI `rules list/current/show/bump` | 新任务默认最新；旧任务改阈值后行为不变（锁定生效） |
| M2 重复检测深化 | 基于感知哈希（PIL+numpy，无 cv2/imagehash 依赖）的镜头级近重复检测；输出重复分组 | 对 xinjiang/park 样片能找出已知重复帧组 |
| M3 语义/内容匹配 | 脚本↔资产元数据+转写 的词法匹配打分，支撑 L5「按文案语义匹配候选镜头」；输出每镜头匹配分 | 给定一段文案，能按语义相关度给候选镜头排序 |
| M4 脚本写作适配器 | 项目无文案入口的脚本草稿适配器 + 强制人工确认回退；`script draft` CLI | 无文案时产出可编辑草稿并落库，必须人工 confirm 才生效 |

## 不在本轮（待决策/工具）

- **OCR**（tesseract 缺失）：需装引擎或接外部 API；本轮不做真 OCR，L4 视觉标签暂用现有元数据/转写。
- **真·embedding 语义**（sentence_transformers 缺失）：M3 先用词法匹配顶上，标注为待升级点。
- **效率校准**：属验收门禁（同事实测 30 分钟标准任务 / 2 小时 4 条），非构建项，仅记录口径。

## 工具链现状

- 可用：Python3.11、numpy、PIL、ffmpeg 8.1.1、SQLite。
- 缺失：cv2、imagehash、tesseract、sentence_transformers。
- 策略：重复哈希与语义打分全部用 numpy+PIL 自力实现，零新依赖。

## 执行顺序

1. M1 规则版本化（地基，其余模块读版本）
2. M2 重复检测
3. M3 语义匹配
4. M4 脚本适配器
5. 集成：两条样片（xinjiang 数字人 / park_sample 项目）复跑验证；清理临时产物；补 README P3 路由；写工作日志。
