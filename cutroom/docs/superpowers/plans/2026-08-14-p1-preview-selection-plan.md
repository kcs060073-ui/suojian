# P1 实施计划：预览选材与可剪素材处理（用户视角版）

> 本文档是设计文档 `2026-08-12-video-production-workflow-design.md` 第 12 节 P1
> 与 `2026-08-13-large-media-progressive-asset-workflow-design.md` 第 13 节 P1 的落地计划。
> 写法原则：每个专业模块先说"对你（使用者）意味着什么体验"，再说具体做什么，最后给验证点。
> 目标：不打开原始大视频，就能快速浏览、筛选、确认素材，并把"选了啥、为什么选"记成可复查的清单。

---

## 一句话概括 P1 是干什么

P0 已经把素材"登记入库、能搜索、能恢复"了。**P1 让你真正"看得清、选得快、记得住"**——
以后挑素材不用逐个双击打开几 GB 的原片，而是在素材库里像翻相册一样扫一眼、听一段试听、看一张拼接图，
就决定这段要不要；所有决定都留痕，换人或过几天回来都能接上。

---

## 模块清单（专业名 → 你的体验 → 做什么 → 验证）

### 1. 缩略图（thumbnail）
- **对你意味着什么**：每个图片/视频在素材库里都有一张"封面小图"。几百个文件一眼扫过，不用逐个打开，像翻手机相册。
- **具体做什么**：用 FFmpeg 给图片生成小图、给视频抽首帧；存到 `cache/thumbnails/`，可删可重建。
- **验证**：素材库列表能显示缩略图；删除缓存后重新生成一致。

### 2. 接触表（contact sheet）
- **对你意味着什么**：一段长视频自动"均匀抽几张关键画面拼成一张长图"。你**不播放视频**就知道这段拍了啥、中间有几秒可用，挑素材快十倍。
- **具体做什么**：FFmpeg 按时间均匀抽帧拼成网格图，存 `cache/contact-sheets/`。
- **验证**：接触表时间点与原片时间码对应；缓存清理后可重建。

### 3. 按需代理（proxy，低清小副本）
- **对你意味着什么**：大视频生成一份"低清流畅版"。卡顿的原片用代理流畅拖拽预览，**原片不动、不占满硬盘**；只有需要连续审看/识别的片段才生成，省空间。
- **具体做什么**：FFmpeg 转低码率低分辨率副本，存 `cache/proxies/`；记录旋转/帧率/音画偏移，剪辑点一律存原片时间码。
- **验证**：代理与原片时间码一致；渲染前抽查代理点对应原片画面无偏差。

### 4. 音频预览（audio preview）
- **对你意味着什么**：音频/视频里的声音有"试听片段"，**不用整段听完**就能判断这段有没有人声、值不值得留。
- **具体做什么**：抽一段低码率音频，存 `cache/audio-previews/`。
- **验证**：点一下能试听；可重建。

### 5. VAD 人声区间 + 粗转写
- **对你意味着什么**：自动标出"**哪几秒有人在说话**"，并把说的话粗略转成文字。你快速判断这段同期声有没有用、是不是拍废话、有没有隐私信息，**不用自己逐段听**。
- **具体做什么**：用 VAD 检测人声区间；对人声区间做低成本粗转写（不承诺 100% 准确，辅助判断）。
- **验证**：人声区间时间码正确；粗转写文本可辅助筛选。

### 6. 明显音频异常检测
- **对你意味着什么**：自动揪出"爆音 / 长时间静音 / 电流杂音"的片段，**提前知道哪段声音有问题**，别等到渲染完才发现要返工。
- **具体做什么**：分析响度曲线，标出异常区间打风险标签。
- **验证**：已知坏片段能被标记。

### 7. 场景片段（segment，自动切镜头）
- **对你意味着什么**：长视频按"镜头变化"自动切成一段段。选素材时直接拿"**现成的小镜头**"，而不是自己手动掐时间码，省事且切得准。
- **具体做什么**：按画面变化切分，每段给 `segment_id` + 原片时间码；时间码可直接喂给 FFmpeg。
- **验证**：片段时间码能直接用于渲染；不破坏全库使用。

### 8. 图片筛选 + 候选/拒绝/确认
- **对你意味着什么**：给每个素材打"**要 / 不要 / 待定**"标签。选材决定有记录、不靠脑子记；换人也能一眼接上，不重复劳动。
- **具体做什么**：在素材上加 `candidate/rejected/confirmed` 状态，写进 SQLite 主账本（不另建文件覆盖）。
- **验证**：状态可改可查；人工确认优先级正确。

### 9. 项目任务目录 + 素材检查表映射
- **对你意味着什么**：把"**这条视频要用哪些素材**"记成一张选材单。审片人一眼看清用了啥、为什么用，不用来回翻聊天记录。
- **具体做什么**：建立 `task.json` 任务目录；素材 ID 映射到园区素材检查表（已有的极简 Excel 业务验收工具）。
- **验证**：一条片对应一张选材单；与检查表对得上。

### 10. 团队核心包装资产清单 + 本地扩充 + 浏览目录
- **对你意味着什么**：BGM / 音效 / 字幕模板 / 贴纸 / 花字等"包装素材"也登记成**可浏览的库**。做包装时不乱翻文件夹，方案能预览并**确认一次**（设计铁律：包装必须人工确认，不静默通过）。
- **具体做什么**：建核心包装资产清单、本地扩充目录、资产浏览目录，接入 P0 素材库。
- **验证**：包装资产可浏览、可试听；方案需人工确认才生效。

### 11. 代理与原片时间码一致性（质量保障）
- **对你意味着什么**：你在代理上选的切点，渲染时用原片**精准对上**，不会因为低清副本偏几秒导致剪错位置——这是"所见即所剪"的底线。
- **具体做什么**：生成代理时统一记录旋转/帧率/音画偏移/色彩空间；渲染前抽查偏差，有偏差阻止渲染并重建代理。
- **验证**：旋转、可变帧率、音画同步、时间码一致；偏差能拦住。

### 12. 基础画面校正（非破坏性调色）
- **对你意味着什么**：暗画面提亮、过曝压低、白平衡等。**预览和成片用同一组参数**，你看到的≈剪出来的；原片文件不改，随时可重来。
- **具体做什么**：非破坏性参数（提亮/压低/对比/白平衡/饱和/HDR 转普通屏），代理与原片共用。
- **验证**：校正同时正确作用于代理预览与最终原片。

### 13. 缓存容量限制 + 安全清理
- **对你意味着什么**：缩略图/代理设上限，**硬盘不会被预览图撑爆**；清理只删"可重建的缓存"，绝不误删原片或成片。
- **具体做什么**：缓存独立容量上限；每周查空间，剩 20% 提醒；只自动清可重建项，中间版本列清单经你确认再清。
- **验证**：缓存超限触发清理；原片/成片零误删。

### 14. 跑通一条园区 + 一条数字人（人工协同第一版）
- **对你意味着什么**：用真实业务证明"**选材 → 确认 → 出片**"整条链路在你这儿跑得通，不是纸上谈兵。
- **具体做什么**：各挑一条真实样片，走完 P1 全部能力 + 现有 render-mix / 数字人管线，端到端人工审片。
- **验证**：两条样片通过人工审片；现有字幕/FFmpeg 结果不回归。

## 建议实施顺序（P1 内部再分小步，按依赖排）

1. **P1-A 预览缓存层**（模块 1–4）：先让"不打开原片就能看/听"成立。这是后面所有功能的基础。
2. **P1-B 音频分析**（模块 5–6）：在预览基础上加人声/异常判断，帮快速决策。
3. **P1-C 候选管理**（模块 7–9）：把"看了→决定→记录"闭环，接任务目录与检查表。
4. **P1-D 包装资产库**（模块 10）：让包装可浏览可确认。
5. **P1-E 质量保障**（模块 11–12）：时间码一致性 + 非破坏性调色，保证"所见即所剪"。
6. **P1-F 安全清理**（模块 13）：横切所有缓存，防撑爆硬盘。
7. **P1-G 端到端样片**（模块 14）：园区 + 数字人各一条，真刀真枪验收。

---

## 明确不做（护栏，不跑偏）

- 不为全库强制生成完整代理（只按需）。
- 不做网页/桌面界面（本期靠命令行 + 你来看）。
- 不做多人多机同时写入、不做中心服务器。
- 不碰 Remotion、不绑剪映原生工程、不重写现有 FFmpeg 引擎。
- 不跳级做 P3 的 OCR / 场景识别 / 语义匹配（那些是 P3 的活）。

## 验证清单（对齐设计文档"后续阶段必测"）

- [ ] 接触表 / 代理 / 音频区间与原片时间码一致
- [ ] 缓存清理后可按需重建
- [ ] 场景片段时间码可直接用于 FFmpeg
- [ ] 同源素材重复能提示
- [ ] 人工标签/确认优先级正确
- [ ] 旧 `public/library` 流程不受影响
- [ ] 园区 + 数字人样片端到端人工审片通过
- [ ] 代理与原片在旋转/帧率/音画同步/时间码一致
- [ ] 基础调色同时作用于代理与原片
- [ ] 隐私风险（人脸/车牌/屏幕/工牌/二维码/联系方式）可标记进入人工确认
