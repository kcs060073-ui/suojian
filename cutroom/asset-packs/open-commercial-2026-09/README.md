# CUTROOM Open Commercial 2026-09

精选用于招商、园区、产业与信息流广告的开放商业素材包。

- `bgm/`：5 首 CC BY 4.0 背景音乐，发布时必须署名。
- `sfx/`：20 个 Kenney CC0 音效。
- `stickers/`：15 个 Kenney CC0 透明 PNG。
- `licenses/`：下载时保留的许可证副本。
- `manifest.json`：来源、授权、哈希、用途和 CUTROOM 资产 ID。

转场为 FFmpeg xfade 参数预设，不包含第三方视频模板。字幕、文字卡和花字为基于开放字体的本地参数预设。
