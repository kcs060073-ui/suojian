剪辑工作台 使用手册

固定入口：http://127.0.0.1:8765/。关闭浏览器不会取消后台任务；重新打开后从 SQLite 任务账本恢复。

首次使用

  1. 打开“设置 → AI 服务连接”，先添加供应商账号。
  2. 至少配置并测试“文案策划”；制作信息流广告还必须配置“配音”。
  3. 在“镜头素材”登记本次主素材目录，需要时添加通用补充目录。
  4. 打开“包装素材”试听或预览当前可用资产。
  5. 回到“任务”，新建视频并按页面显示的当前动作逐步推进。绿色已完成步骤可点击只读回看；橙色步骤是任务真实所在阶段，尚未开始的步骤不可点击。

回看历史步骤不会改变门禁、版本或后台状态。页面会显示“只读回看”和“返回当前步骤”；需要修改已锁定内容时，仍使用对应的返工入口。

独立模式与 Agent 模式

  • 独立模式：剪辑工作台 自己调用已配置的文案/分镜模型。
  • Agent 模式：当前 Codex、WorkBuddy 或豆包工作模型完成文案与分镜；剪辑工作台 不调用文本模型。
  • 两种模式：豆包 TTS、Seedance 等生产服务仍使用 剪辑工作台 各自凭据。

新建任务时选择规划方式。Agent 模式进入分镜阶段后会显示“等待 Agent 提交规划”，请回到当前使用的 Agent 继续；四个人工门禁仍只能在 剪辑工作台 页面确认。

WorkBuddy

WorkBuddy 使用本地 stdio，不填写 URL 或 Authorization。安装 剪辑工作台 MCP 后，还要在连接器管理页找到 cutroom，点击“信任”并启用，再重启 WorkBuddy 或新建会话；只写入配置不会让旧会话自动获得工具。

豆包工作

豆包工作使用本机 HTTP。先在 剪辑工作台 目录运行 scripts\start-doubao-work-mcp.ps1 并保持窗口开启，再在第二个 PowerShell 窗口运行 scripts\show-doubao-work-mcp-config.ps1。在“插件 · 技能 · 伙伴 → 新建自定义连接器”中选择 HTTP，填写 http://127.0.0.1:8766/mcp，并添加名称为 Authorization 的 Header。

Authorization 的完整值以 Bearer 开头，相当于本机连接密码。不要截图、分享或写入文档；若已经泄露，应删除 runtime\mcp\doubao-work.token、重启服务并更新连接器。

怎样验证

调用 cutroom_get_system_status。Codex、WorkBuddy、豆包工作应分别返回对应的 clientId；mcpToolCount = 12 是完整 MCP 工具数，allowedTaskActionCount = 4 只是一个动作工具允许启动的四种动作。旧字段 agentActions 也表示动作，不是工具总数。

Agent 返回的任务地址形如 http://127.0.0.1:8765/#/tasks/<task-id>，需要先保持当前工作台会话可用。关闭某个客户端的 MCP 不会删除 剪辑工作台 和现有任务。

配置大模型

第一步：添加供应商账号

填写供应商预设和自己能识别的名称。豆包 API Key用于合成、试听和连接检测，AK/SK用于自动刷新音色目录，AppID + Access Token是旧版兼容项，可以留空。保存并检测会生成极短的测试语音。所有密钥只进入 Windows 凭据管理器。

第二步：建立三类模型配置

  • 文案策划：独立模式下由文案分析、分镜规划和包装推荐共用；Agent 模式不需要。
  • B-roll：只有本地素材缺画面时才调用，属于可选付费能力。
  • 配音：信息流广告的试听和正式 TTS；数字人口播路线不调用。

同一类可以保存多个模型并设置默认项。配置名称只是给人看的，例如“智谱-文案策划”；模型 ID 必须填写供应商真实提供的精确 ID。

第三步：测试连接

只有最近 24 小时内真实测试通过的配置才能被新任务选择。任务创建后冻结本次指定的供应商、地址、模型和音色，失败时不会静默换模型。

普通豆包配置不填写模型 ID 或音色 ID：选择配音服务版本后，从自动获取的中文音色目录中选择常用音色；新建广告时仍可为本条视频改选其他声音。

管理镜头素材

  • 本次主素材：只服务当前项目或当前视频，优先用于配片。
  • 通用补充素材：跨项目可复用的城市空镜、办公、交通、科技等画面。

使用前先做最小归类

素材根目录和盘符都由同事自行选择，剪辑工作台 不要求固定路径。先由人工把项目专属素材按“一个项目一个目录”分开，并把可跨项目复用的素材放入独立的通用目录；暂时分不清的素材可放入 99_待整理。不需要逐个重命名视频，也不必一次整理完全部旧素材。

系统负责扫描、建立索引、搜索和候选匹配，但不会自动移动、重命名或重新整理原片，也不应只依赖 AI 判断素材属于哪个项目。有版权、授权或隐私疑问的素材不要放进可用于正式任务的目录。

登记和更新

每个项目目录分别登记为本次主素材，通用目录登记为通用补充素材。新增视频放入正确目录后点击“检查更新”；移动硬盘盘符变化时使用“重新连接”，不要删除后重新建库。原片不会被复制进数据库，系统只保存索引、指纹、代理和时间码。

管理和应用包装素材

包装素材分字幕、音色、BGM、音效、文字卡、贴纸、花字、Logo/水印八类，并按三层组织：

  1. assets/：项目随附的核心资产。
  2. asset-packs/：团队共享扩展包。
  3. 个人目录：默认是 assets-local/<分类>/inbox/，也可在“设置 → 存储与缓存”选择自己的根目录，Git 忽略。

每位同事可自定义个人包装素材根目录；系统会自动建立八类子目录。切换只更新指向，不搬迁或删除旧文件；目录离线时保留配置，可重新选择并连接。

设计优先级是个人 → 团队 → 核心；同名覆盖必须显示来源。在素材库点击“检查新增与更新”可只读报告新增、变化、缺失和损坏文件，但不会自动登记，也不会把未知授权文件变成可选素材；新素材仍需补齐资产 ID、来源、授权、标签和 manifest 登记。

应用顺序固定为：选择方案 → 单项试听/查看 → 必要时复制并替换或关闭可选项 → 生成真实预览 → 播放至 90% 或结束 → 确认方案 → 可选保存为个人模板 → 正式渲染。预览已过期、渲染失败或文件缺失时必须重新生成；授权不明或文件缺失的素材不能进入正式成片。

数字人混剪完整流程

  1. 新建任务，选择“数字人混剪”。
  2. 选择禅镜最终 MP4，粘贴与视频口播完全一致的最终文案。
  3. 选择文案策划模型、主素材目录和需要的通用补充目录；B-roll 模型可选。
  4. 运行创建前预检并创建任务，人工锁定文案。
  5. 系统转写时间戳、同步素材并生成 AI 分镜候选。
  6. 逐镜头采用、替换、拆分、删除或调整顺序，确认后锁定画面。
  7. 试听单项、生成并完整观看真实包装预览，确认方案后由系统渲染并自动 QA。
  8. 完整播放候选成片，确认通过后生成发布包。
粗剪区直接显示任务实际采用的图片或视频，并可按镜头顺序连续播放。右侧候选先点选只做临时预览；再次点击“用所选候选替换当前镜头”并确认影响范围后才会保存。图片不显示入点/出点裁剪；任一镜头素材离线或无法读取时，系统会指出具体镜头并阻止画面锁定。
任务页的 12 步分为“准备输入、调整画面、成片检查、交付发布”四组。先看“本步要做”，需要回看时点击分组中的已完成步骤。系统处理说明、替换候选和质检通过证据都可按需展开；自动 QA 的阻断项必须先处理。

信息流广告混剪完整流程

  1. 新建任务，选择“信息流广告混剪”，填写最终广告文案、用途、时长和画幅。
  2. 选择文案策划模型和配音模型；本地画面不足时再选 B-roll 模型。
  3. 绑定主素材与通用补充目录，预检后创建并锁定文案。
  4. 系统按锁定原文逐句生成分镜和 TTS，再从任务绑定的素材库逐句配片。
  5. 检查每句话的声音、画面和节奏；任何一句没有真实素材都不能锁画面。
  6. 确认画面，生成并完整观看真实包装预览；确认方案后渲染，自动 QA 通过后完整审片。
  7. 人工确认后生成发布包。

四个人工门禁、审片和发布包

必须由人确认：最终文案、画面顺序、本片包装方案、完整观看后的成片。自动测试或自动 QA 都不能替代完整观看。

标准发布包包括最终 MP4、三张封面、发布文案、发布检查 JSON 和 QA 报告。当前不自动发布到平台。

中断、失败和存储

  • 模型失败：先查看页面给出的鉴权、地址、模型或网络错误；重新测试后再发起新请求。
  • 素材离线：使用重新连接保留原素材 ID，不要新建一套重复素材库。
  • 任务中断：只使用页面提供的“从安全检查点继续”，付费调用结果不明时不会自动重试。
  • 空间不足：在“设置 → 存储与缓存”先预览再确认；只清理已登记的可重建预览缓存，不删除原片、成片或数据库。

新手首片检查清单

  • 文案策划模型显示“可用”；广告任务的配音模型也显示“可用”。
  • 数字人 MP4 与最终文案完全一致，或广告文案已经定稿。
  • 主素材目录在线且已检查更新，每句话都有可用画面。
  • 包装方案中的文件存在、授权状态满足使用要求。
  • 画面锁定后，在包装阶段即可登记自摄且可商用的镜头素材，供后续任务复用；其他有授权的素材只确认用于本片。已有旧候选时，登记后重新渲染并质检。
  • 完整播放候选片，确认字幕、声音、节奏、事实和隐私后再批准。照片停留不再按视频卡顿报警，非阻断警告仍需人工复核。
  • 发布页显示规定文件完整后再交付。
