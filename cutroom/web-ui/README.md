# 剪辑工作台 · 同事视频工作台

剪辑工作台是现有本地视频自动化方案的同事入口，不是通用剪辑软件。普通同事只在网页里选择输入、确认四个关键节点；转写、分镜、匹配、渲染、质检和发布包都由本机服务按 SQLite 任务账本执行。

完整同事操作流程见 [剪辑工作台同事操作手册](../docs/user-guide/cutroom-user-guide.md)，工作台右上角也可直接打开网页版手册。首次配置模型或需要给同一类添加多个模型时，见 [剪辑工作台多模型与供应商配置](../docs/operations/model-profiles-new-api.md)。默认可以直接填写官方 API Key、API 请求地址和模型 ID；New API 不是前置条件。

## 日常打开

固定网址：**http://127.0.0.1:8765/**

首次安装或项目移动位置后，在项目目录运行一次：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File workbench/install-autostart.ps1
```

以后 Windows 登录时会在后台启动剪辑工作台。页面打不开时，先双击根目录的 `启动出片工具.bat`，等出现“视频制作工作台已启动”后刷新固定网址。服务只监听 `127.0.0.1`，不会开放给局域网或公网。

## 两种规划方式

- 独立模式：剪辑工作台自己调用已配置的文案/分镜模型。
- Agent 模式：当前 Codex 模型完成文案与分镜；剪辑工作台不调用文本模型。
- 两种模式：豆包 TTS、Seedance 等生产服务仍使用剪辑工作台各自凭据。

新建任务时选择规划方式。Agent 模式下，创建页不再要求文案策划模型；任务进入“AI 分镜”后会显示“等待 Agent 提交规划”，请回到 Codex 继续。四个人工门禁仍在剪辑工作台页面完成。Agent 返回的任务地址形如 `http://127.0.0.1:8765/#/tasks/<task-id>`，只有已有工作台会话时才能直接打开。

Codex MCP 是可选功能，不影响剪辑工作台独立运行。关闭 MCP 时只移除 Codex 中的剪辑工作台服务项，现有剪辑工作台和任务继续可用。

## 第一次制作数字人视频

1. 在“镜头素材库”登记本次项目素材目录；不同项目分别登记。
2. 如有跨项目共用的空镜、图片等，再登记为“通用补充目录”；可设为默认，也可在每条任务中单独勾选。
3. 使用独立模式时，在“设置”配置“文案策划”模型；Agent 模式不需要文本模型。需要生成缺失画面时再配置 B-roll。每一类都能保存多个模型配置。密钥保存到 Windows 凭据管理器，SQLite 和页面响应只保留配置状态，不返回密钥。
4. 在“任务”点击新建，选择“数字人混剪”，选择禅镜最终 MP4、粘贴与该 MP4 完全一致的最终口播文案，再选本任务要用的模型、一个主素材目录和需要的通用补充目录。
5. 先运行环境预检。阻断项必须处理；时间或费用显示“暂无法估算”时表示没有可靠依据，不代表 0。
6. 创建后先看页面上方的“本步要做”。12 步按“准备输入、调整画面、成片检查、交付发布”分组；点击分组可查看其中步骤，已完成步骤可只读回看，当前步骤用橙色标出，未来步骤不可进入。回看不会改变门禁、版本或后台状态。
7. 每步的系统说明和技术记录可以按需展开。画面调整先点镜头，再在右侧查看、替换；自动 QA 先处理阻断项，警告项按时间点复核，通过证据默认折叠。

## 制作信息流广告

1. 新建任务时选择“信息流广告混剪”，填写广告最终文案、投放目的、目标时长、横竖画幅和本次主素材目录。
2. 预检通过并锁定文案后，先同步素材，再确认 AI 分镜与 TTS 调用；系统按锁定原文逐句生成配音并只在本任务绑定的素材库中配片。
3. 检查每句镜头。任何一句没有真实素材时都不能锁定画面；补选素材后再确认画面、包装方案并出片。
4. 自动质检通过后完整观看候选片，人工确认后才能生成发布包。

自摄且可商用的镜头素材可在画面锁定后的包装阶段一次登记并按素材指纹复用；仅获本片授权的素材使用“仅确认本片”入口。已有旧候选时，登记后须重新渲染，旧候选报告不会改写。照片的正常静止画面不计为卡顿；警告由审片人员复核，真峰值等阻断仍需生成达标的新候选。

一期主链固定为：

`创建与预检 → 文案锁定 → 素材增量同步 → AI分镜推荐 → 粗剪 → 调整画面顺序 → 画面锁定 → 包装方案确认 → 精剪成片 → 自动质检 → 完整审片 → 发布包`

四个必须由人确认的门禁是：最终文案、画面顺序、当前视频的包装方案、完整审片。包装素材库是长期资产；包装方案是当前这一条视频选用的组合，可以采用推荐，也可以复制后自行更换单项。

AI 收敛为三类：文案策划、B-roll 和配音，镜头匹配在本机完成。任务创建时冻结本次选择的精确模型、网关和渠道；执行不会跟随以后修改的默认项，也不会静默换模型。B-roll 只在本地素材缺口时按需调用。页面在每次外部模型调用前显示输入范围、影响和费用提示；确认只生成候选，不会越过人工门禁。

关闭浏览器不会取消后台任务。重新打开后看板与列表读取同一 SQLite；失败或中断时，仅在服务端确认可恢复后显示“从安全检查点继续”。

## 管理与验收

正式任务账本默认在 `runtime/workbench/catalog.sqlite`。不要直接编辑 SQLite、任务目录或发布包。

制作隔离验收副本：

```powershell
.venv\Scripts\python scripts\prepare_workbench_acceptance.py
```

目标已存在时默认拒绝；确需重建时使用 `--replace`，脚本会先备份旧副本。源库只读并在操作前后核验 SHA-256。

启动指定验收库并执行冒烟检查：

```powershell
.venv\Scripts\python -m workbench.server --db runtime\workbench\acceptance\p2-xinjiang-v2.sqlite --port 8765 --no-open
.venv\Scripts\python scripts\smoke_workbench.py --base-url http://127.0.0.1:8765 --task p2-xinjiang-v2 --startup-key <本次启动密钥>
```

启动密钥只用于当前本机首次换取浏览器会话，不写入报告或源码。冒烟检查会核对真实任务、看板/列表同源、十二步、受控视频预览、四门禁、七文件发布包、越权/越目录拒绝和响应无密钥。

移除登录自启：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File workbench/install-autostart.ps1 -Remove
```

`web-ui/server.js` 仅兼容旧 Node 启动命令并转交 Python 服务，不再承载旧网页后端。
