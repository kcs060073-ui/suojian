# 剪辑工作台 beta.8 使用说明

本页补齐当前源码中使用手册与界面检查所引用的版本说明，不增加新的功能验收结论。它是溯剪剪辑与审片流程的本地执行组件。

## 配音配置

- 豆包 API Key 用于合成、试听和连接检测。
- AK/SK 用于自动读取音色目录。
- AppID 与 Access Token 属于旧版兼容字段，可以留空。
- “保存并检测”会请求极短的测试语音，以实际返回结果显示配置状态。

文案策划、补充画面和配音按任务各自选择配置。服务调用与费用仍以使用者的实际账户和确认操作为准。

## 制作流程

选择视频类型，准备文案和素材，检查输入，再依次完成镜头、包装、预览与完整审片。后续交付以已审看候选及实际发布包为依据。

当前自动化检查和开发机验证不替代普通使用者电脑、素材环境与实际首片验收；未完成的路线仍以项目验收记录为准。

更多操作参见[同事使用手册](../docs/user-guide/cutroom-user-guide.md)和[模型配置说明](../docs/operations/model-profiles-new-api.md)。内部目录、接口及配置字段保留兼容命名。
