- 精简重复说明和入口，删除分析页的重复真人口播按钮、右上角草稿状态与替换原片选择框。侧栏使用完整收起按钮，仍可展开。

## 视频与字幕

- 公开直链与平台链接读取支持分段下载、Range、HLS/DASH 和本地合并；保留地址校验、下载上限及原子发布。
- 新片场安全验证与登录需求分开提示。网页能播放或显示下载按钮不保证无验证读取成功，不能绕过验证码或付费权限。
- OCR 先确认可靠口播，再用稀疏探测确认相应字幕，满足门槛才执行完整识别。无可靠口播或无匹配字幕时跳过，主要用于核对脚本。
- 旧任务保留原始数据；新规则不会自动改写已完成的分析。

## rea-video 独立环境

上游：[JuneYaooo/rea-video](https://github.com/JuneYaooo/rea-video)，锁定提交 `3522250b4d3e667610a175c0f188ac3d725b41cd`。随仓库提供的 Skill 保留 Apache-2.0 许可证与来源说明；引擎源码和模型不打包。

完成主项目安装后，可单独执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\main\scripts\setup-rea-video.ps1
```

该脚本联网安装到 `main/.rea-venv`，不安装到 `main/.venv`，不运行视频分析或 VLM。核心依赖按已验证的 Windows Python 3.11 环境锁定在 `main/requirements-rea.txt`，不安装会抢占 OpenCV 的 GUI/OCR 依赖。

主工作台默认使用项目内 CLI。已有独立环境时可设置 `SUOJIAN_REA_CLI` 指向 `rea-video.exe`；`REA_VIDEO_MODELS` 指定已准备的模型缓存，默认 `main/model_cache/rea-video`。

网页以 `--no-vlm --no-stems --no-ocr --no-packaging --workers 1 --lang zh` 运行子进程，并禁用分析进程的外部 HTTP 代理访问。结果写入 `main/work/method-analysis/<job>`，不覆盖主剪辑蓝图。模型未准备时可能降级或失败，日志保存在对应任务目录；本版本未验证在全新电脑上完整安装 rea-video。

制作方法属于离线初判，均需结合原片复核。AE 是复刻分工建议，不能认定原作者使用了 AE。此更新不自动调用付费 VLM、生成视频或发布作品。
