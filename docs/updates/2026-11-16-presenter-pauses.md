# 真人口播选句：保留相邻句之间的停顿

按原顺序选中同一素材中的相邻句子时，预览和草稿会连续保留从第一句到最后一句的源视频范围，包括中间的画面和原声停顿，不再因间隔超过 1 秒而剪掉停顿。字幕仍逐句独立，计划总时长包含保留的停顿。

不同素材、倒序选句或中间漏选了实际口播内容时仍分别剪辑，不会把未选的话带回来。自动匹配脚本的原有间隔规则保持不变；此规则适用于手动选句流程。已有预览和草稿不会被自动覆盖，需要重新生成才能采用新规则。

回归检查覆盖长停顿、多句连选、字幕偏移与独立性、未选话语、倒序和跨素材选句。另用本地生成的音视频实际生成预览和可编辑草稿，检查保留范围、句间静音、句内声音及草稿视频/字幕轨道；人物识别在该时间测试中使用替身，没有对真实出镜人物进行视觉验收。

源码发布与本地服务加载分别确认，不以测试通过代替正在运行的服务已更新。

同时修复草稿素材迁移时的路径别名问题：JSON 中的 Windows 短路径或其他未规范化路径按已验证的源文件映射到新草稿目录，不再仅依赖字符串前缀。路径归属测试比较规范化后的目录；增加实际非规范路径回归用例，防止草稿仍引用旧导出素材。
