## 实现与复验

- 复用现有解析器、公网地址检查、大小及时间上限、分段下载和音画合并。
- 公开页面状态仅通过 JSON 解码读取，不执行网站脚本，不导入登录 Cookie。
- `main/scripts/probe_video_links.py --report PATH URL [URL ...]` 默认只验证元数据；显式添加 `--download-dir PATH` 才下载原片。
- 下载验收要求：原作品编号一致、视频轨道有效、预期音轨存在、时长合理、首尾可解码。页面可打开、HTTP 200 或取得标题均不等于下载成功。
- 本轮平台读取、直链与分段下载相关 43 项测试通过。自动检查已纳入新增页面适配测试。

本轮没有增加依赖，也不包含原始视频、临时播放地址、验证缓存或本机配置。源码发布与本地运行服务加载分别验收。
