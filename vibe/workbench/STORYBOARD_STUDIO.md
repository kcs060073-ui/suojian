# 独立分镜渲染工作台

入口 `/storyboard`；分镜工作台原生模板仍在 `/`。两者复用同一任务库和分镜记录，不是两套应用。

用户填写剧本、实景图、画风参考图、画幅和要求，保存后将启动指令发到执行对话。执行对话读取任务输入和素材；依据剧本撰写镜头叙事、逐镜生图提示词，使用对话可用的 image 工具生成图片，并通过分镜接口登记图片与文字。工作台本身不能调用对话中的 image 工具，也不会在保存任务后自行产生图片。参考图中的业务事实需要核实；图片保存为待审看，不能自动确认。

分镜工作台按两个上传区区分用途：`scene` 为实景图，用于在保留主要真实场景特征的前提下制作美术化画面；`other` 为画风参考图，参考风格、线条与色彩。若服务尚未保存 `referenceGroups`，读取 `reference` 中的分组数量并按 `materials` 顺序还原；旧版单一 `referenceRole` 不能覆盖这两组用途。手动填写的路径用途依照用户的创作要求判断。有画风参考图时优先参考该图，未提供时再使用任务选择的风格。

风格模板库保存在 `work/production/visual-styles/`：可以上传参考图并填写喜欢的视觉特点，也可以在已有分镜审看页收藏单镜或整套分镜。收藏会复制参考图片，记录原任务、原脚本、镜头说明和审稿状态；被收藏并不意味着视觉验收通过。新任务选择模板时保存对应版本快照，后续修改模板说明不会改写已保存任务。执行对话应读取 `input.visualStyle.references` 中的图片及描述，结合本次剧本创作；模板里的旧脚本和分镜作为示例，不作为新任务事实。模板是可复用参考，并不会训练或更新模型权重。

模板库可从分镜页面顶部打开。每个已保存的风格支持继续添加参考图片，生成新版本并保留旧版；内置风格补图时会另存一份新风格，原有内置参考不变。可以展开查看每个模板的全部参考图。

模板卡片接受拖入图片，最后加入的参考图显示为封面；同一批多张图片按文件修改时间排序。执行对话以 `visualStyle.references` 中最后一张为主要风格参考，并根据任务需要使用其他参考；本次任务单独上传的画风参考图仍优先。鼠标悬停或键盘聚焦模板参考图可查看大图。

新建模板后会询问是否删除当前选中的旧模板；仅在用户确认后移入回收站。模板也可手动删除并从回收站恢复，已有任务的图片与版本快照继续保留。自建模板可以修改名称，生成新版本。模板卡片按图片比例完整显示封面，悬停时可进一步查看大图。旧版服务不支持回收站，需使用新版服务。

自建模板卡片上的“修改名称”和“修改说明”会在卡片内打开编辑区；保存时可同时修改两项，图片和旧版本保留。取消不会保存，空名称不能提交。内置风格先另存为新风格后再编辑。

用户可在分镜页面审看、编辑文字、导入或替换图片、确认图片和动效计划。更换图片或修改描述会使相关计划失效，必须重新审查。执行对话根据已确认的图建立并保存逐镜动效计划；如果选用 Seedance，计划的 `execution_method` 是 `seedance`，且 `prompt` 填写完整动态说明。所有分镜及计划确认后，页面提供按镜头启动 API 视频生成的可选按钮。点击才会提交一次，可能产生费用。

视频入口复用 `outputs/seedance-poc01/seedance_poc.py` 中既有的剪辑工作台只读凭据读取和 Seedance 请求格式；不启动剪辑工作台 MCP、不迁移数据库、不输出密钥。先保存分镜、动效哈希及脱敏请求，异步轮询和下载后进行片段登记，状态为待用户审看。若生成期间对应分镜或计划变化，结果仅保存在独立任务目录，不绑定至新计划。提交结果不明、轮询中断或超时不会自动重复提交。当前页面尚不支持从中断状态继续轮询，需先由执行对话核对原任务；服务重启后可能留下进行中状态。

最近实际调用记录为账号欠费而遭拒，本次新入口仅做模拟服务验证；不意味着当前账号已恢复。必须精确的中文和界面信息仍需后期独立处理，模型生成的视频内容为预渲染素材，不等于可编辑图层。
