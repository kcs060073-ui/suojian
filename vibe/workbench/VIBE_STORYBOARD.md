# 园区 Vibe · 简笔画叙事：当前接入说明

工作台入口为 `http://127.0.0.1:8796/`。保存任务不会启动制作；明确启动后，对话读取任务编号、输入修订与输入哈希。选择“简笔画叙事”可不提供实景素材；“实景招商”和“混合表达”仍需提供素材。

本阶段可保存执行对话编写的结构化镜头清单和美术说明、导入分镜图片、逐镜提出修改、恢复历史图片、确认全部分镜、保存并确认逐镜动效计划、登记并验收镜头片段。导入或替换图片不会确认它。修改或恢复某镜头的图片使该镜头的旧计划及片段失效，不动其他镜头。

使用方法：工作台“制作任务”找到任务，点击“查看任务”→“查看与确认分镜”；逐镜审查后，可填写意见并标记待修改，或者点击“确认全部分镜，进入动效分析”。确认后在执行对话中要求分析；当前页面不会自动调用 AI，也不会自行制作视频。动效计划保存后，逐镜确认计划；已有实际片段可以按执行方式登记，播放后人工验收。

执行对话可通过本机 API 使用 `/api/production/tasks/<任务编号>/storyboard` 读取分镜状态；创建和变更分别提交 `/create`、`/board`、`/request_changes`、`/select_board`、`/confirm_all`、`/plan`、`/confirm_plan`、`/register_clip`、`/accept_clip`、`/request_clip_changes`。创建需当前 `expectedRevision`、`inputHash`、`artDirection` 和按时间排序的 `shots`，每镜至少含 `id`、`start`、`end`；变更还需当前 `expectedSerial`，逐镜操作需 `shotId`。冲突时读取最新状态，不可覆盖历史。

动效计划须由执行对话查看用户最终确认的图片后编写，`elements` 每项包含 `element_id`、`action_type`、`start_time`、`duration`、`motion_description`、`start_state`、`end_state`、`execution_method`、`prompt`、`required_assets`、`overlay_requirements` 和 `validation_rules`。方法仅接受 `seedance`、`programmatic`、`footage`、`hybrid`。确认计划需该版 `planSha256`。片段登记仅允许项目 `outputs/` 或 `work/` 下的 MP4，校验视频流、时长、画幅和哈希；实际视频是历史产物时，要核对它确实与当前分镜和计划一致，不能只凭文件存在宣称已经执行计划。片段验收需该版 `clipSha256`，状态体现人工选择，不等同自动画质或业务真实性校验。

限制：本阶段尚无自动脚本拆镜、AI 图像识别、各执行器统一调度、批量导图、全局渲染防绕过或基于已验收独立镜头的可编辑剪映草稿。当前门禁只覆盖本分镜接口及任务 `rendering`、`deliver` 状态入口，旧 `/api/tools` 通用入口尚未绑定任务；执行对话必须遵守分镜与计划确认后才做动态生成的约定。不要把接口记录、历史 Seedance 成功、文件写入或程序校验视为用户艺术验收。

剧本 10 的当前任务为 `V20261028-ef5af8a5`，输入 r1，六张既有静态分镜均待用户审查；原始口播和事实待核事项保留，镜头 02、03 既有试片尚未在该任务中验收。没有因接入发起新的视频模型请求。
