# 园区 Vibe V2：第一批升级与现状

本次是工作区和独立预览版本，不代表整套 V2 已完成，也没有切换现有共享服务。

## 简要架构映射

- 共用任务、输入修订及影片版本：`workbench/production.py`；分镜、图片、动效计划及片段验收：`workbench/vibe_storyboard.py`；网页：`workbench/static/studio*`。
- 制作追踪：`workbench/production_trace.py`；实际记录范围见 `outputs/optimization-01/制作追踪与基线保护-交付说明.md`，不能推断覆盖所有新片段。
- Shotcraft、MotionGit 和 Canvas 曾在隔离环境执行原生样片；Remotion 是渲染运行时，不是独立风格模板。来源与状态见 `outputs/native-skill-validation-02/原生Skill视觉能力验证报告.md`。Spotlight 与 RowEmbed 适配执行过，园区视觉验收未通过或未验证，见 `outputs/native-park-adaptation-03/`；P04 包装为隔离原型，未接入默认生产。
- P0 审计中，普通信息流使用 Cutroom，真人口播使用本地匹配链路；Hypit 是独立实验，不能宣称已经接入本次双路线调度。剪映已有不同输出路径，但尚无根据本分镜工作台已验收片段组装的统一草稿。
- 已有 Seedance 调用实验；最近六镜实际请求因账户欠费遭拒，无生成结果，见 `outputs/vibe-workflow-v11/factory-seedance-six-e676fc0d/执行报告.md`。本次未调用模型。

## 本批落地

双路线和业务预设、默认风格选择、参考用途进入任务输入并随输入版本保存。默认风格引用已确认六镜中的第一张裁片作为风格参考，并记录文件哈希，不复用其内容。风格参考缺失时会在页面说明；程序化样片标为待验收。

既有分镜审看增加编辑说明、逐镜提示词字段和动态制作说明；修改镜头说明保留历史并使对应图片重新审稿、旧计划失效。外部模型片段可按已确认的 `external` 计划导入；继续使用现有人工确认和验收机制。

## 尚未完成

- 风格库目前只有一个内置母版及自定义输入；新增、复制、停用、风格版本管理和自定义参考图的独立资产绑定仍待实现。
- 页面不能自主调用 AI 理解脚本生成分镜，也不能在页面新建完整镜头清单；目前需制作对话编写并保存结构化分镜。逐镜提示词由已填写字段组装，缺失信息提示补充，不是模型自动分析。
- 动效方案仍由制作对话编写；外部模型的首尾帧、多人候选选择、子镜头拆分、自动匹配和完整任务调度未实现。内部模型调用未接入新界面。
- 原生模板路线目前提供路线选择并保留既有模板库；没有实现依照镜头推荐、原生执行调度与自动适配，也不能证明已进入最终片段。
- 本次没有建立按镜头多来源混剪的通用时间线、剪映草稿组装或 GUI 验证；画面内预渲染动效不能宣称逐元素可编辑。
- 旧通用工具入口仍不受此分镜状态门禁统一约束。不要绕过人工审稿和验收，不能把文件生成视为视觉验收。

## 运行与测试

工作区使用独立端口 `18976` 进行预览；该进程退出后网址不可用。现有主应用及共享服务未重启或切换。旧服务若读取新版前端，但未加载新版接口，会提示需要新版服务，避免悄悄丢失路线信息。
