# 溯剪制作分工与本地运行

## 锁定来源与运行

上游 https://github.com/JuneYaooo/rea-video ，提交 `3522250b4d3e667610a175c0f188ac3d725b41cd`。Skill 用安装脚本从该提交下载。仅 SKILL.md 增加溯剪入口与触发描述，另加本参考文件。升级时比较上游差异并回归验证，不用浮动 main 覆盖本地规则。

发布版在 `main/.rea-venv` 使用独立 Python 3.11 环境。可显式运行 `main/scripts/setup-rea-video.ps1`，锁定上述上游提交。主程序默认读取项目内 CLI，也可用 `SUOJIAN_REA_CLI` 指定已安装的 CLI。模型缓存默认为 `main/model_cache/rea-video`，可由 `REA_VIDEO_MODELS` 指定。不要将模型、个人分析结果和凭据提交到公开仓库。

依赖维护与分析输出均使用独立目录。严格离线分析前确认模型缓存齐全；当前网页默认关闭 VLM、分轨、OCR 和包装检测，分析不触发付费模型。详见项目 `docs/updates/2026-11-11.md`。

默认离线取证，由当前可看图的 agent 复核。声音分析按任务需要启用分离并试听。OCR、人脸和音轨分离模型缺失时可能下载，严格离线任务先检查缓存，缺失则说明降级。退出码为零后仍检查 JSON、总览与截图完整可读。分析输出独立保存，避免覆盖生产任务和已有报告。

付费 VLM、视频生成、后续制作和生产任务写入按用户授权执行。上游 route 或 engine 字段属于计划元数据，不代表生成已获授权。仅安装或分析时不运行 remake-run、不自动确认分镜。读取配置只检查字段与可用性，不输出密钥。不因上游提及偏好就自动写 Codex 记忆或 prefs/correct，写入遵循用户明确请求。

## 逐镜判断与分层

先读时间轴、元数据、字幕及包装候选，再看联系表与逐镜首中尾帧。形变、跟踪、边缘稳定性需要密集抽帧或短段复核，单图不能证明动态行为。报告写明实际看过的段落、VLM 是否生效、声音是否试听。

分别给出原片来源判断和复刻分工建议。前者引用证据、置信度和未知项，后者按底图、主体动作、相机运动、文字图表、遮罩、声音、转场拆层。AE 建议不代表原片确由 AE 制作。低置信分类保留待复核，画风、无噪声或平台转码不能单独证明 AI 来源。

| 内容或任务 | 复刻分工建议 | 验收重点 |
|---|---|---|
| 风格化场景底图、自然主体动作 | AI 生图或图生视频，再剪辑组装 | 主体、结构、画风和帧间一致性 |
| 单图推拉、平移、缩放、简单旋转 | 剪辑软件关键帧 | 原图完整、运动平稳、时序准确 |
| 切镜、变速、字幕、简单花字、配音和音乐卡点 | 剪辑；复杂字效可交 AE | 文案、声音同步与可编辑性 |
| 精确数字、Logo、产品与真实项目素材 | 原素材 + 剪辑或 AE 合成 | 数字、形状与来源准确 |
| 透视跟踪、复杂遮挡、路径线条、分层视差、复杂版式动效 | AE，主体底层可结合 AI | 跟踪贴合、遮罩稳定、层次可控 |
| 固定纸白与淡出边缘，内部运动 | 固定纸白层 + 内容遮罩，按复杂度选剪辑或 AE | 四周逐帧静止，不溢出、不裁原图 |
| 必须精确一致的复杂三维空间 | 标记 3D 或人工制作需求，评估 AI 辅助 | 几何与视角一致 |

同镜可以建议“AI 制作内部主体动作 → AE 固定边缘并合成标注 → 剪辑加字幕与声音”。简单平移缩放直接用剪辑关键帧，精确跟踪、复杂遮挡或分层才推荐 AE。不强制所有镜头三选一。

四周纸白与淡出边缘完全静止适用于固定纸白手绘风格。该风格分析时区分整张画布和内部内容运动，沿用“制作片段”的固定边缘提示词，其他风格按当次要求。提示词本身不能保证固定边缘，验收需逐帧检查，必要时用固定纸白层和遮罩。

## 交付约定

中文报告先给总体分工，再给逐镜表。每行包含镜头 id、起止时间、内容层、原片来源判断、建议分工、依据、所需素材、具体做法和验收点。同镜多层可分行。未知软件或模型名称明确标为未知，不为没看过的镜头编造证据。

保留上游 breakdown.json，将补充建议放在同目录 `production-routing.md`。用户需要机器数据时再提供 `production-routing.json`，它是补充结构，不冒充上游 schema 或溯剪生产任务。

JSON 顶层包含 schema（`suojian.production-routing.v1`）、breakdown_path、shots。每镜包含 shot_id、start、end、source_assessment（label、confidence、evidence、unknowns）、layers。每层包含 name、route、reason、inputs、steps、acceptance。route 可用 ai、editing、ae、3d、footage、needs_review，组合用多个 layer 表达。原片来源与复刻 route 分开记录，沿用上游 id 与时间轴，拆镜建议另列。

Skill 提供分析和分工建议。AE 工程制作、自动生成、页面接线及生产任务写入按后续用户任务执行。
