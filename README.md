# 溯剪 SuoJian

### 从参考视频中读懂剪法，把创意变成可继续编辑的视频作品

溯剪是一套运行在 Windows 本机的视频创作工作台。它结合参考视频分析、园区视频与动画制作、Cutroom 素材管理和剪辑流程，帮助创作者从一条参考片出发，梳理镜头、字幕与节奏，再结合自己的文案和素材制作新作品。

你可以在浏览器里查看分析结果、调整方案、审看片段，并按实际流程输出成片或剪映草稿。涉及素材授权、内容确认、费用和最终发布的决定，仍由使用者完成。

> **项目状态：** 本仓库是 Windows 本机源码快照，包含溯剪主工作台、园区 Vibe 和 Cutroom beta.8。首次安装需要联网；部分能力需要额外的模型、服务配置和本地素材。不同机器及剪映版本的兼容性需要实测。

## 项目亮点

| 能力 | 可以做什么 |
| --- | --- |
| 参考视频分析 | 读取视频信息，识别镜头切点、粗略运动和节奏，整理为可查看的剪辑蓝图。 |
| 字幕与声音分析 | 分别查看语音识别、画面文字、字幕候选及其冲突；支持可选音频分轨和声音结构分析。 |
| 剪法模板与新脚本 | 基于参考片保存剪法信息，输入新文案，检查字幕、时长和适配提示。 |
| 园区 Vibe | 提供园区视频、分镜、视觉风格和动画讲解相关的工作台与渲染组件。 |
| Cutroom 剪辑流程 | 管理本地素材、挑选镜头、配置字幕与声音包装，生成预览、执行质检并准备交付。 |
| 剪映草稿 | 在用户确认后尝试输出基础可编辑草稿，供后续在兼容版本的剪映中继续处理。 |

识别结果是辅助创作的候选信息：字幕可能有错字，镜头运动、贴纸和音效等判断也需要人工复核。

## 三个模块如何协作

```text
参考视频 ──→ 溯剪主工作台 ──→ 剪法分析 / 新脚本方案
                                   │
                  园区 Vibe ←──────┼──────→ Cutroom
              分镜与视觉创作                  素材、剪辑、包装与审片
                                   │
                                   ↓
                       预览、确认 → 成片或剪映草稿
```

- **`main/` · 溯剪主工作台**：分析参考视频，展示镜头、字幕和声音等信息，生成结构化蓝图，并提供剪映草稿适配与 Cutroom 集成入口。
- **`vibe/` · 园区 Vibe**：提供园区视频、分镜工作台、视觉组件、风格模板和基于 Remotion 的渲染相关代码。
- **`cutroom/` · Cutroom**：提供素材目录、预览选材、数字人混剪、信息流广告、包装、审片和发布包等能力。

各模块的可用程度取决于已安装的依赖、素材与服务配置；部分历史实验和模板仍需在目标电脑上单独验证。

## 快速开始

### 1. 准备环境

请使用 **64 位 Windows**，提前安装并配置到 PATH：

- Python **3.11**，包含 Python Launcher（`py`）。
- Node.js LTS 和 npm。
- FFmpeg 和 ffprobe。

在新打开的 PowerShell 中检查：

```powershell
py -3.11 --version
node --version
npm --version
ffmpeg -version
ffprobe -version
```

首次安装需联网下载依赖与浏览器组件，语音相关依赖体积较大，请预留足够的磁盘空间。需要剪映草稿功能时，还应在本机安装兼容的剪映专业版。

### 2. 下载项目

在 GitHub 页面点击 **Code → Download ZIP**，完整解压后使用；不要直接在压缩包内运行。也可以使用 Git 克隆到较短路径：

```powershell
git -c core.longpaths=true clone https://github.com/kcs060073-ui/suojian.git C:\suojian
```

### 3. 安装并启动

1. 双击项目根目录的 **`安装溯剪.bat`**，等待安装完成。
2. 双击 **`启动溯剪.bat`**，在本机浏览器打开 [http://127.0.0.1:8788/](http://127.0.0.1:8788/)。
3. 使用期间保持主工作台窗口开启；关闭窗口会停止主工作台。

安装器会在项目内创建独立的 Python 环境、安装 Node 依赖和浏览器组件，并将项目中四个 Skill 登记到当前用户的 Codex；如果已有同名 Skill，会保留原版本。重新打开 Codex 后可刷新技能列表。项目移动位置后，需要重新安装以更新目录链接。

启动脚本默认也会检查并启动本机 Cutroom 服务；园区 Vibe 按需启动。详细说明见 [Windows 安装指南](INSTALL.md)。

> 只测试基础界面时，可使用 `powershell -ExecutionPolicy Bypass -File .\install.ps1 -CoreOnly`。该模式不包含完整语音、OCR 和音频处理依赖，不能视为完整安装。

## 一次典型创作流程

1. **导入参考片。** 在溯剪工作台选择本地视频，运行分析，查看镜头、字幕、声音与节奏候选。
2. **检查分析结果。** 对照原片核对字幕、画面文字、镜头及声音标记；这些结果不保证完全准确。
3. **准备新作品。** 输入自己的文案，选择所需的剪法、园区素材和创作方式，确认素材使用权及可能发生的服务费用。
4. **制作与预览。** 根据任务进入 Vibe 或 Cutroom，调整分镜与素材，检查字幕、声音和视觉包装，再生成预览。
5. **人工审看与交付。** 完整观看并处理质检提示；按实际使用的流程生成成片、交付包或剪映草稿，在目标软件中检查后继续编辑和发布。

Cutroom 工作流包含文案、画面顺序、包装方案和完整审片等人工确认环节。自动质检不能代替对事实、授权、隐私与最终观看体验的检查，也不会自动发布到视频平台。

## 参考视频分析与剪映草稿

溯剪将参考片分析和新作品方案分开保存：

- `edit_blueprint.json`：参考视频的镜头、节奏、样式和分析结果。
- `draft_blueprint.json`：用户的新脚本、素材槽位匹配及确认状态等草稿方案。

分析阶段用于查看和调整方案；生成草稿需要用户明确确认。分析结果并不等于对原视频效果的精确还原：复杂转场、字体资产、花字、贴纸、逐字动画和音效素材等，可能只能近似或无法恢复。

溯剪与 Cutroom 的集成可在确认后创建和查看任务，并在交付条件满足时尝试转换为剪映草稿。**可编辑程度取决于使用的生成路径、交付内容以及本机剪映版本**；压制在成片画面中的效果不一定能逐项编辑。建议先用小样片在自己的电脑上完整验证。

更详细的功能与限制见 [主工作台说明](main/README.md) 和 [溯剪 × Cutroom 统一流程](main/UNIFIED_WORKFLOW.md)。

## 园区 Vibe 与视觉创作

园区 Vibe 包含分镜、视觉风格、模板及渲染相关组件，可辅助园区介绍、动画讲解等视频创作。仓库中的运行时使用 **Remotion 4.0.539**，依赖定义位于 [`vibe/work/runtime/`](vibe/work/runtime/)。

当前 Remotion 运行时保留 Zod 4.3.6；安装可能出现版本建议提示。项目记录中简单测试片已能渲染，复杂模板仍需逐项验证。模板功能代码存在，不代表个人收藏图片、私人授权素材或所有外部模板都已包含。

分镜和工作台细节可参阅 [Vibe 分镜说明](vibe/workbench/VIBE_STORYBOARD.md) 与 [分镜工作室说明](vibe/workbench/STORYBOARD_STUDIO.md)。

## Cutroom：从素材到审片

Cutroom 面向数字人混剪与信息流广告等制作任务，支持登记本地素材库、浏览候选镜头、调整画面顺序、选择字幕与声音包装，随后生成预览并进行质检和审片。

建议先把**项目专属素材**与**通用补充素材**分开整理，再在 Cutroom 中登记和检查更新。原片存放在你选择的磁盘目录中；仓库不包含你的历史素材、数据库和任务。

数字人路线通常需要已完成的口播视频及对应文案；信息流广告路线通常需要定稿文案、可用素材和配音服务。部分模型规划、配音、生成式视频及试听功能依赖外部服务，可能产生费用。

日常操作与确认要求见 [Cutroom 同事操作手册](cutroom/docs/user-guide/cutroom-user-guide.md)；素材或音乐使用前，请核实授权并阅读 [第三方素材说明](cutroom/THIRD_PARTY_NOTICES.md)。

## 使用前需要自行准备

- **素材与项目数据：** 原始视频、图片、个人模板图片、历史任务、成片、剪映草稿和本地数据库均不会随仓库恢复。
- **模型与在线服务：** 本地语音模型可能在首次使用时下载；在线模型、配音或 Seedance 需自行配置对应服务与凭据，费用以服务商实际规则为准。
- **OCR：** 如果选择使用 Tesseract，还需单独安装程序及中文语言包。
- **私人授权资源：** MotionGit 私人授权包及个人风格图片不在公开仓库内，需自行取得有效授权并导入。
- **剪映：** 需要本机安装兼容版本；实际草稿是否可打开、各轨道是否可编辑，需要在目标版本中逐项检查。

不要把 API 密钥、用户媒体、个人信息、数据库或本机任务记录提交到公开仓库。仓库中保留的第三方代码与资源应遵循各自的许可证和来源说明。

## 常见问题

**安装失败或提示找不到命令？** 先检查安装窗口中的第一个报错，并确认 `py -3.11`、`node`、`npm`、`ffmpeg` 和 `ffprobe` 在新终端中可运行。源码应完整解压到较短路径。

**浏览器打不开工作台？** 确认安装已完成、启动窗口仍在运行，并检查本机 `8788`、`8765`、`18979` 端口是否被已有服务占用。不要为了排查直接删除已有数据库或素材。

**字幕识别或分轨不可用？** 检查是否使用了基础安装模式，以及对应可选依赖、模型和网络是否可用。首次使用本地语音模型可能需要下载权重。

**剪映草稿无法打开或效果不一致？** 先确认剪映版本、草稿路径和素材是否可用，再用小样片测试；复杂效果和部分交付路径并不保证逐项可编辑。

**切换到新电脑后看不到历史任务？** 历史数据库、用户素材与个人模板不在源码仓库中。请在保留备份的前提下，按原环境和实际需要迁移；不要直接覆盖正在使用的 Cutroom 安装。
